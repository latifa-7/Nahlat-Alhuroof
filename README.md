# 🐝 نحلة الحروف — Nahlat Al-Huroof

تطبيق لتعليم الأطفال (5–12 سنة) **النحو والإعراب** (24 درسًا) و**الإملاء** (10 دروس) مع وكيل ذكي اسمه «نحّولة».
مشروع مادة AIG 101 – Introduction to AI & Society، فصل خريف 2026/2027.

## التنزيل
- **أندرويد:** من صفحة [Releases](../../releases/latest) نزّل `NahlatAlhuroof.apk` وثبّته.
- **آيفون / آيباد:** افتح رابط GitHub Pages للمستودع في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية». يعمل بدون إنترنت بعد أول فتح.

## محتويات المستودع
| المجلد | المحتوى |
|---|---|
| `src/` | الكود المصدري: المحتوى التعليمي (`data.js`) ومنطق التطبيق والوكيل (`app.js`) |
| `web/` | النسخة الجاهزة (تُنشر كتطبيق ويب قابل للتثبيت) |
| `android/` | مشروع أندرويد يعرض التطبيق ويوفّر النطق العربي |
| `.github/workflows/` | يبني ملف APK وينشر نسخة الويب تلقائيًا عند كل تعديل |

لإعادة بناء `web/index.html` بعد تعديل `src/`: `cd src && python3 build.py && cp index.html ../web/`

## الخصوصية
كل البيانات محفوظة على جهاز الطفل فقط ولا تُرسل إلى أي خادم.
